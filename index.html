Institut Teknologi & Sains Mandiri · Panduan Pengujian Proof of Concept (PoC)

1. Stored XSS (Cross-Site Scripting) Celah Aktif

Komentar pada Forum Diskusi Kelas disimpan permanen di database dan dirender ke HTML menggunakan innerHTML tanpa sanitasi. Script jahat akan tereksekusi pada browser civitas akademika yang membuka forum.

<img src=x onerror="alert('🔴 [STORED XSS TERPICU] Origin: ' + location.origin)">
2. IDOR / Kontrol Akses Lemah Celah Aktif

Halaman KHS & Transkrip Nilai mengambil data nilai mahasiswa berdasarkan parameter identitas (NIM) tanpa memverifikasi hak milik sesi akun aktif. Mahasiswa A (Meca) dapat melihat transkrip nilai rahasia mahasiswa B (Siti / Budi).

Ubah parameter NIM target ke: 24781015
3. Eskalasi Hak Akses (Privilege Escalation) Celah Aktif

Parameter role pada formulir Biodata & Profil Akun dapat dimanipulasi oleh klien tanpa otorisasi backend. Mahasiswa biasa dapat menaikkan hak aksesnya menjadi Dosen atau Admin secara instan.

Ganti role menjadi 'admin' di Pengaturan Profil
4. Validasi Berkas Lemah (Unrestricted Upload) Celah Aktif

Formulir E-Learning & Pengumpulan Tugas tidak memvalidasi ekstensi file atau tipe MIME. File script web .html berisi payload jahat dapat diunggah dan dieksekusi langsung saat dibuka.

Unggah payload_backdoor.html dan buka file
Bonus: SQL Injection (Login Bypass) Celah Aktif

Klausa login memproses query mentah yang dapat dibypass dengan statement tautologi ' OR '1'='1 --.

Username: ' OR '1'='1 -- | Password: sembarang
