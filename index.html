1. Stored XSS (Cross-Site Scripting)

Injeksi Skrip Permanen pada Forum Diskusi

Input teks komentar tidak disanitasi dan disimpan di basis data, kemudian dirender langsung menggunakan innerHTML. Skrip JavaScript yang disisipkan akan dieksekusi secara otomatis di browser siapapun yang membuka forum diskusi.

<img src=x onerror="alert('Stored XSS Ditemukan! Origin: ' + location.origin)">
2. IDOR / Kontrol Akses Lemah

Insecure Direct Object Reference pada KHS & Transkrip Nilai

Halaman KHS mengambil data nilai mahasiswa berdasarkan parameter identitas (NIM) tanpa memverifikasi apakah akun mahasiswa yang sedang login berhak melihat data tersebut. Mahasiswa A (Meca) dapat melihat transkrip mahasiswa B (Siti / Budi).

Ganti target_nim=24781015 pada menu Lihat Nilai
3. Eskalasi Hak Akses (Privilege Escalation)

Manipulasi Parameter Role Pengguna via Form Profil

Sistem mempercayai parameter role yang dikirim dari klien pada pengaturan profil akun mahasiswa tanpa validasi izin wewenang (Mass Assignment / Role Tampering). Mahasiswa biasa dapat menaikkan hak aksesnya menjadi Dosen atau Admin.

Ubah role='admin' pada Profil Mahasiswa
4. Validasi Berkas Lemah (Unrestricted File Upload)

Unggah Berkas Eksekutabel / Web Skrip (.html, .svg) pada Tugas

Formulir pengumpulan tugas menerima berkas dengan tipe ekstensi apapun tanpa pemeriksaan MIME type atau filtering ekstensi berbahaya. Berkas .html berisi payload jahat dapat diunggah dan dieksekusi saat dibuka oleh penguji/dosen.

Unggah payload_backdoor.html dan buka berkas via Review Tugas
Bonus: SQL Injection

Bypass Otentikasi Login Admin

Klausa WHERE pada query login dibypass menggunakan statement tautologi ' OR '1'='1 sehingga penyerang dapat masuk langsung sebagai Administrator tanpa mengetahui kata sandi sebenarnya.

Username: ' OR '1'='1 -- | Password: sembarang
